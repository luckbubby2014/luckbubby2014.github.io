WHY THIS EXISTS

为什么仍然
以本地为先。

《星陨哨站》的目标很具体：一款打开就能玩、关掉就结束的桌面游戏。 不强制登录，没有日常任务，也不需要保持联网；账号与群组只是可选的延伸。

所以它现在的形态是：一艘舰船、一片深空、不断刷新的敌潮。 武器自动开火，你控制移动、冲刺和脉冲新星；每局 5–15 分钟， 阵亡或撤离后结算星尘，用于永久强化。

这个网站同样如此。没有分析脚本、广告或第三方追踪， 安装包由 GitHub Releases 提供。断网之后，游戏仍可正常游玩；只有登录、群组与发布功能需要联网。

01

本地优先

存档、成就、进度与战报默认都在你的电脑上。账号是可选的，只在你登录后同步星尘、群组与战报。

02

把话说清楚

签名状态、Gatekeeper 限制、平台要求与已知问题都写在下载页，不藏在脚注里。

03

少而完整

与其堆十个半成品系统，不如让九种武器、三种星区和五十一项成就各自站得住。

HOW IT'S BUILT

技术构成。

游戏由 Electron 承载，战斗与界面使用 Canvas 2D 与原生 DOM 绘制。所有视觉元素都由代码生成或随包分发。

RUNTIME

Electron

桌面外壳负责窗口、全屏与本地存档读写。游戏主体是一个打包在应用内的静态前端。

RENDER

Canvas 2D

舰船、敌群、弹道、粒子与背景全部由 Canvas 2D 绘制，没有外部贴图依赖。

AUDIO

Web Audio

音效与背景音乐由运行时合成，跟随战局强度变化，不需要联网串流。

SAVE

JSON · Schema v3

存档以纯 JSON 写入本地文件，启动时做规范化迁移。没有数据库，也没有加密锁死。

SITE

Astro + Supabase

站点在构建时生成静态 HTML；账号、群组与 Newsroom 发布使用可选的 Supabase 服务，页面本身不加载分析脚本。

DATA

Source of truth

网站的武器、属性、星区与成就数据由游戏源码自动生成，避免两处维护后对不上。

HONEST LIMITS

当前版本
不支持的功能。

它提供 macOS 与 Windows 两个桌面版本，核心游戏只在本机运行。macOS 需要 Apple Silicon 与 macOS 12+， Windows 提供 64 位免安装包。官网支持 8 种界面语言，安装包不需要额外语言包。 账号与群组榜单是可选的，不登录也能完整游玩；目前没有实时多人模式。联网只用于更新检查、可选的账号同步与战报分享，不会静默替换应用。 手柄支持是基础的，不是完整 UI 导航。

macOS 安装包使用 ad-hoc 签名，未经过 Apple 公证；Windows 包没有代码签名证书。 首次打开必须手动放行。这不是“即将修复”的临时状态，而是当前分发方式的真实限制。
