FIRST RELEASE

首航

第一个可对外分发的完整版本。包含核心生存循环、九种武器、长期成长、51 条成就与行动战报。

核心战斗

  • 九种自动开火武器：脉冲步枪、散射炮、环刃、电弧、卫星炮、感应雷、轨道长枪、追猎导弹、等离子喷流。
  • 十四项局内属性，覆盖伤害、攻速、暴击、护盾、处决、相位冷却等方向。
  • 四系武器流派与 2 / 4 件套协同加成；武器满级并与对应属性联动后可进化。
  • Boss、精英、分裂体、布雷艇、远程炮舰等敌种，按生存时间逐步加压。

战场系统

  • 三种星区：残骸带、离子风暴、哨站废墟，各自拥有不同的密度与收益倍率。
  • 六种出击祝福与六种遗物舱增益，均为单局生效。
  • 每局抽取三份战术合约，覆盖击杀、生存、精英、Boss、信标与遗物目标。
  • 数据信标、战场随机事件、陨石雨、超载浪潮与精英悬赏。

长期成长

  • 星尘经济、十一项星核强化、九项研究协议。
  • 备用舰体、军械库解锁、预置挂载与升级重抽。
  • 五十一项成就，六个分类，四个层级，带完成度、进度与解锁日期。
  • 跨局生涯统计与最近二十次出击记录。

呈现与体验

  • 每局生成四段式行动战报，包含 S 至 D 评级与一键复制。
  • 开场动画、舰船与全部敌舰的 Canvas 2D 重绘。
  • 设置项包含界面缩放、色盲模式、闪光、震屏、伤害数字、音量与自定义键位。
  • 存档结构 v3，支持旧版存档的规范化迁移。

已知限制

  • 仅提供 Apple Silicon 版本，暂无 Intel 或 Windows 构建。
  • Ad-hoc 签名、未公证，首次打开需要手动放行。
  • 无自动更新、云同步、在线排行榜与多人模式。
  • 手柄支持为基础映射，尚未提供完整的手柄 UI 导航。
VERSION POLICY

关于版本号、存档与更新。

SEMVER

主版本.次版本.修订号

当前处于 0.x 阶段。新增系统与内容会提升次版本号，修复与平衡调整提升修订号。0.1.0 是首个公开构建。

SAVE COMPATIBILITY

存档结构 v3

游戏启动时会规范化旧存档，缺失字段使用默认值补齐。未来若必须迁移结构，会在版本记录中明确说明。

UPDATE METHOD

手动覆盖安装

当前没有自动更新器。下载新的 DMG 后，把应用拖进 Applications 覆盖旧版本即可；本地存档不受影响。

NOT PLANNED

目前没有的计划

暂无 Intel 构建、Windows 版本、云存档、在线排行榜与多人模式。若未来支持，会单独发布说明。
