LATEST RELEASE

账号与群组

加入可选账号、最多 10 人的群组、日 / 周 / 月榜单，以及结算后分享到群组的完整闭环；官网同步上线个人页面与 Newsroom 发布后台。

账号与同步

  • 游戏内新增「账号与群组」，可注册、登录、退出并同步游戏状态。
  • 星尘、成就数量、总出击与最佳记录会出现在官网个人页面。
  • 登录状态保存在本机；离线战报会排队，联网后自动补传。

群组与榜单

  • 创建或加入最多 10 人的群组，用 6 位邀请码即可。
  • 日 / 周 / 月三张榜单：折线趋势、总分开列、最佳分数与用时。
  • 结算页新增「分享到群组」，确认后队友会在群组动态里看到这一局。
  • 没有群组时会提示先创建，不会丢失本局战报。

官网

  • 新增账号页、个人页面与群组页，8 种语言完整覆盖。
  • Newsroom 支持站长在网页内直接发布带封面图的更新，并与静态记录合并。
  • 下载、FAQ 与隐私说明同步为「账号可选、离线可玩」。

RELEASE

更新检查

加入真实的版本检查与更新下载：读取 GitHub Releases、显示下载进度、校验 SHA-256，并自动打开 DMG。

版本与更新

  • 设置新增「版本与更新」页，直接读取 GitHub Releases 上的最新发布。
  • 启动时最多每 6 小时静默检查一次，也可以随时手动重新检查。
  • 发现新版本后可在应用内直接下载 DMG，并显示实时下载进度。
  • 下载完成后自动打开 DMG，并用同名 SHA-256 校验文件完整性。
  • 主菜单新增更新入口，发现新版本时直接显示目标版本号。

分发与隐私

  • 不会静默替换应用：下载后仍需手动拖进「应用程序」覆盖旧版。
  • 除检查与下载外保持离线，不上传存档、遥测或账号数据。
  • 更新包与校验文件来自 GitHub Releases，下载量可公开核对。

FIRST RELEASE

首航

第一个可对外分发的完整版本。包含核心生存循环、九种武器、长期成长、51 条成就与行动战报。

核心战斗

  • 九种自动开火武器：脉冲步枪、散射炮、环刃、电弧、卫星炮、感应雷、轨道长枪、追猎导弹、等离子喷流。
  • 十四项局内属性，覆盖伤害、攻速、暴击、护盾、处决、相位冷却等方向。
  • 四系武器流派与 2 / 4 件套协同加成；武器满级并与对应属性联动后可进化。
  • Boss、精英、分裂体、布雷艇、远程炮舰等敌种，按生存时间逐步加压。

战场系统

  • 三种星区：残骸带、离子风暴、哨站废墟，各自拥有不同的密度与收益倍率。
  • 六种出击祝福与六种遗物舱增益，均为单局生效。
  • 每局抽取三份战术合约，覆盖击杀、生存、精英、Boss、信标与遗物目标。
  • 数据信标、战场随机事件、陨石雨、超载浪潮与精英悬赏。

长期成长

  • 星尘经济、十一项星核强化、九项研究协议。
  • 备用舰体、军械库解锁、预置挂载与升级重抽。
  • 五十一项成就，六个分类，四个层级，带完成度、进度与解锁日期。
  • 跨局生涯统计与最近二十次出击记录。

呈现与体验

  • 每局生成四段式行动战报，包含 S 至 D 评级与一键复制。
  • 开场动画、舰船与全部敌舰的 Canvas 2D 重绘。
  • 设置项包含界面缩放、色盲模式、闪光、震屏、伤害数字、音量与自定义键位。
  • 存档结构 v3，支持旧版存档的规范化迁移。

已知限制

  • 仅提供 Apple Silicon 版本，暂无 Intel 或 Windows 构建。
  • Ad-hoc 签名、未公证，首次打开需要手动放行。
  • 无静默自动更新、实时多人模式；账号、云同步与群组榜单为可选功能。
  • 手柄支持为基础映射，尚未提供完整的手柄 UI 导航。
VERSION POLICY

版本号、存档与更新方式。

SEMVER

主版本.次版本.修订号

当前处于 0.x 阶段。新增系统与内容会提升次版本号，修复与平衡调整提升修订号。0.1.0 是首个公开构建，0.1.1 加入应用内更新检查与下载，0.1.2 加入账号、群组与战报分享。

SAVE COMPATIBILITY

存档结构 v3

游戏启动时会规范化旧存档，缺失字段使用默认值补齐。未来若必须迁移结构，会在版本记录中明确说明。

UPDATE METHOD

应用内检查 · 手动安装

设置 →「版本与更新」会读取 GitHub Releases 上的最新版本，并可直接下载、校验 DMG。下载后仍需手动拖进 Applications 覆盖旧版，不会静默替换。

NOT PLANNED

目前没有的计划

暂无 Intel 构建、Windows 版本与实时多人模式。账号、云同步与群组榜单已经上线，但完全可选；未来若加入实时联机，会单独发布说明。
