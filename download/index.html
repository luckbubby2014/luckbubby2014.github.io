DOWNLOAD FAQ

安装与放行

为什么 macOS 提示「无法验证开发者」？
安装包使用 ad-hoc 签名，没有 Apple Developer ID，也没有经过 App Store 公证。macOS 对首次打开的下载应用会执行隔离检查，因此会拦截。这是预期行为，不代表文件损坏。
如何安全地首次打开？
在「应用程序」里找到「星陨哨站」，按住 Control 点击（或右键），选择「打开」，再在弹窗里点「打开」。如果系统设置里出现拦截提示，也可以在「隐私与安全性」中点「仍要打开」。
终端里那行 xattr 命令是做什么的？
xattr -dr com.apple.quarantine "/Applications/星陨哨站.app" 会移除该应用上的隔离属性，让 macOS 不再对这次下载做首次校验。它只影响这一个应用路径，不会关闭系统 Gatekeeper，也不会修改其他应用。
这个版本有自动更新吗？
有更新检查，但不是静默自动更新。设置 →「版本与更新」会读取 GitHub Releases 上的最新版本；发现新版本可直接下载对应平台的安装包（macOS 为 DMG，Windows 为 ZIP），并通过 SHA-256 校验。安装仍需手动覆盖旧版，存档不会丢失。除检查与下载外，游戏保持离线。
支持哪些平台？
macOS 版支持 Apple Silicon（M1 及后续芯片），系统要求 macOS 12 Monterey 或更高；Windows 版是 64 位免安装包，支持 Windows 10 / 11。Intel Mac、Linux 与 iOS 暂不支持。
为什么没有上架 Mac App Store？
这是一个独立项目，账号与云同步都是可选的，也没有应用内购买。当前以 DMG 和 ZIP 直接分发，省去商店审核和强制账号依赖，也方便你自行备份安装包。
安装包有多大？
macOS 的 DMG 约 107 MB，Windows 的 ZIP 约 132 MB。安装后应用约 250 MB 左右，主要来自 Electron 运行时、游戏代码和音频资源。游戏不需要联网下载额外素材。
Windows 版怎么安装？
下载 ZIP 后解压到任意可写目录，双击 StarfallOutpost.exe 即可运行。这是免安装包，不会写入系统目录，也不需要管理员权限；首次运行可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」即可。
能把游戏装到外置硬盘吗？
可以。macOS 把「星陨哨站.app」拖到任意可写的 APFS 或 HFS+ 卷即可；Windows 直接解压到外置盘。存档始终写在当前用户的配置目录下，不会跟着应用去外置硬盘。
