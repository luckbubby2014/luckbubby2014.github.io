下载与安装
01 / FAQ

平台与安装

支持哪些平台？
macOS 版支持 Apple Silicon（M1 及后续芯片），系统要求 macOS 12 Monterey 或更高；Windows 版是 64 位免安装包，支持 Windows 10 / 11。Intel Mac、Linux 与 iOS 暂不支持。
为什么没有上架 Mac App Store？
这是一个独立项目，账号与云同步都是可选的，也没有应用内购买。当前以 DMG 和 ZIP 直接分发，省去商店审核和强制账号依赖，也方便你自行备份安装包。
安装包有多大？
macOS 的 DMG 约 107 MB，Windows 的 ZIP 约 132 MB。安装后应用约 250 MB 左右，主要来自 Electron 运行时、游戏代码和音频资源。游戏不需要联网下载额外素材。
Windows 版怎么安装？
下载 ZIP 后解压到任意可写目录，双击 StarfallOutpost.exe 即可运行。这是免安装包，不会写入系统目录，也不需要管理员权限；首次运行可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」即可。
能把游戏装到外置硬盘吗？
可以。macOS 把「星陨哨站.app」拖到任意可写的 APFS 或 HFS+ 卷即可；Windows 直接解压到外置盘。存档始终写在当前用户的配置目录下，不会跟着应用去外置硬盘。
02 / FAQ

Gatekeeper 与签名

为什么 macOS 提示「无法验证开发者」？
安装包使用 ad-hoc 签名，没有 Apple Developer ID，也没有经过 App Store 公证。macOS 对首次打开的下载应用会执行隔离检查，因此会拦截。这是预期行为，不代表文件损坏。
如何安全地首次打开？
在「应用程序」里找到「星陨哨站」，按住 Control 点击（或右键），选择「打开」，再在弹窗里点「打开」。如果系统设置里出现拦截提示，也可以在「隐私与安全性」中点「仍要打开」。
终端里那行 xattr 命令是做什么的？
xattr -dr com.apple.quarantine "/Applications/星陨哨站.app" 会移除该应用上的隔离属性，让 macOS 不再对这次下载做首次校验。它只影响这一个应用路径，不会关闭系统 Gatekeeper，也不会修改其他应用。
这个版本有自动更新吗？
有更新检查，但不是静默自动更新。设置 →「版本与更新」会读取 GitHub Releases 上的最新版本；发现新版本可直接下载对应平台的安装包（macOS 为 DMG，Windows 为 ZIP），并通过 SHA-256 校验。安装仍需手动覆盖旧版，存档不会丢失。除检查与下载外，游戏保持离线。
03 / FAQ

存档与进度

存档保存在哪里？
macOS 位于 ~/Library/Application Support/starfall-outpost/save.json，Windows 位于 %APPDATA%\starfall-outpost\save.json。它是一份本地 JSON 文件，升级或重装应用时不会被删除，除非你手动清理该目录。
换一台电脑怎么迁移进度？
退出游戏后，把 save.json 复制到新电脑相同系统的对应路径即可。macOS 与 Windows 使用相同的存档格式，可以互相迁移。建议先备份原文件，避免两台设备同时覆盖。
成就和星尘是云同步的吗？
默认只保存在本机。登录可选账号后，星尘、成就与战报才会同步到官网；不登录不会上传任何数据，也不会收集遥测。
怎样重置进度？
退出游戏，删除对应平台的 save.json，再重新启动。游戏会生成一份全新的本地存档。此操作不可撤销，请先备份。
04 / FAQ

玩法与体验

一局大概多久？
一次常规出击在 5 到 15 分钟之间。随着生存时间增加，敌人密度、精英频率与 Boss 会持续升级；你可以随时在暂停菜单里主动撤离并结算。
必须用键盘吗？手柄支持吗？
键盘是主要输入方式：WASD 或方向键移动，Space 冲刺，E 释放脉冲新星。游戏也支持标准手柄的基础连接与暂停恢复，但键位提示以键盘为准。
为什么武器会自动开火？
这是幸存者式玩法：射击自动化，把注意力集中在走位、拾取和升级选择上。不同武器有各自的索敌逻辑，构筑的乐趣在于让它们互相补位。
官网支持哪些语言？
官网支持 8 种界面语言：简体中文、繁體中文、English、日本語、Français、Deutsch、ไทย、Español。可在页眉右上角的语言选单中随时切换。
05 / FAQ

隐私与分发

游戏会联网或上传数据吗？
默认离线。只有在你主动检查更新、登录账号或分享战报时才会联网；不会上传遥测或广告数据。音频、贴图与字体都由本地运行时生成或随包分发。
官网会收集访问数据吗？
这个站点不接入广告网络或第三方分析脚本。下载按钮指向 GitHub Releases 上的安装包文件，不会附带追踪参数。账号、群组与 Newsroom 使用可选的 Supabase 服务；托管平台可能按自身隐私政策记录基础访问日志。
可以转载安装包吗？
请保持文件完整并附带来源说明，不要修改签名内容或重新打包后冒充官方版本。若用于公开分发，建议同时提供本文档页的校验值与 Gatekeeper 说明。
