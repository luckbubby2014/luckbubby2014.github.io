POSTED 2026.11.17 01
发布 v2.1

Windows 版上线：免安装 ZIP，解压即玩。

v2 与 v2.1 现在同时提供 Windows x64 免安装包。解压后双击 StarfallOutpost.exe 就能开始，存档结构与 macOS 版完全一致。

两个平台，同一份进度

Windows 包是 132.4 MB 的 ZIP，不含安装程序，也不会写入系统目录或注册表；解压到任意可写目录即可运行，删除文件夹就是卸载。

两个平台使用同一份存档结构：macOS 在 ~/Library/Application Support/starfall-outpost/save.json，Windows 在 %APPDATA%\starfall-outpost\save.json。各自写入本机，不会互相覆盖。

  • 系统要求：Windows 10 / 11（64 位）。
  • 首次运行可能触发 SmartScreen：点「更多信息」，再点「仍要运行」。
  • 更新检查会按平台选择 DMG 或 ZIP，仍然需要你手动确认下载。

下载与校验

下载页新增 macOS 与 Windows 两张卡片，分别给出文件名、大小和 SHA-256；版本记录页的 v2 与 v2.1 也各自提供两个平台的直链。

Windows 包同样附带 .sha256 校验文件，可以用 PowerShell 的 Get-FileHash 对照，确认下载过程没有损坏文件。

POSTED 2026.11.15 02
游戏更新 v2.1

v2.1：同步、补传与重新分享修复。

登录后立即同步并补传离线战报；星尘消耗不会被旧云端值复原；重新分享会把动态移动到当前群组。

同步与分享

星尘同步改为按本地增量更新云端：离线赚到的会补上，花掉的不会被旧值复原。新设备首次登录采用云端进度。

同一局战报重复补传会复用原记录；在战局中退出游戏会先结算并写入本地队列。

POSTED 2026.11.14 03
游戏更新 v2

v2：账号、群组与战报分享。

账号完全可选：不登录仍然只读写本机存档。登录后可以跨设备查看星尘、成就与最佳记录，创建最多 10 人的群组，并在结算页把这一局分享给队友。

可选账号，离线照常玩

账号不是启动游戏的前置条件。没有登录时，存档、成就、星尘与战报仍然只写在本机；登录后才会把星尘、成就数量、总出击与最佳记录同步到官网个人页面。

游戏会记住本机登录状态，重启后继续有效。网络中断时，结算战报会进入本地队列，联网后自动补传，不需要重新打一局。

  • 个人页面：星尘、成就、最佳分数、最近十二局与当前群组。
  • 跨设备：在另一台 Mac 登录同一账号即可看到同步后的记录。
  • 随时退出：设置 → 账号与群组 → 退出登录，不会清除本地存档。

最多 10 人的群组榜单

创建群组后会得到 6 位邀请码，发给队友即可加入；一个群组最多 10 位飞行员。群组页提供日、周、月三张榜单，折线与排名同步更新，按本周期总分排序。

结算页新增「分享到群组」。确认后，队友会在群组动态里看到这一局的评级、分数、生存时间、击杀与构筑；如果还没有群组，会提示先创建一个，战报仍保留在本机。

官网与 Newsroom

官网新增账号页、个人页面和群组页，全部支持中文、English、繁體中文、日本語、Français、Deutsch、ไทย 与 Español。Newsroom 也加入了站长发布后台，可以直接上传封面图并发布更新；发布后的内容会与静态更新记录合并显示。

POSTED 2026.11.12 04
游戏更新 v1.4

v1.4：在游戏里检查并下载更新。

设置 →「版本与更新」现在会读取 GitHub Releases 上的真实发布，显示下载进度、校验 SHA-256，并在完成后打开 DMG。

新的更新入口

主菜单新增「检查更新」。启动时最多每 6 小时静默检查一次，也可以随时手动重查；发现新版本后，按钮会直接显示目标版本号。

下载在应用内完成，结束后自动打开 DMG。安装仍然需要你手动把应用拖进「应用程序」覆盖旧版——不会静默替换，也不会碰本地存档。

校验与隐私

  • 下载时实时显示进度与总大小。
  • 完成后用发布包旁的 SHA-256 校验文件完整性；不一致会删除文件并提示重新下载。
  • 除检查与下载外，游戏保持离线，不上传存档、遥测或账号数据。
